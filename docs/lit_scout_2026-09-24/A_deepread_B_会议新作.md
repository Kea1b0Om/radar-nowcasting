### Cold Diffusion: Inverting Arbitrary Image Transforms Without Noise

- **ID**：arXiv 2208.09392　**Venue**：NeurIPS 2023（依据是网页检索）；本次读到的是 arXiv v1 预印本

- **一句话**：把扩散里的加高斯噪声换成任意确定性退化 D(x0,t)（模糊、遮挡、下采样、雪化、去色、混入动物图），用 L1 训练复原网络 R(x_t,t) 直接回归 x0；采样时用差分更新 x_{s-1}=x_s−D(x̂0,s)+D(x̂0,s−1)（Alg.2）。在一阶线性退化假设下，这个更新对复原网络 R 的误差免疫。实验只在自然图像上做（MNIST/CIFAR-10/CelebA/AFHQ），指标是 FID/SSIM/RMSE。对我方有两点价值：它是强度截断阶梯 min(y,τ) 和 SDIR 频率截断级联的共同概念祖先；另外提供一个零训练成本的读出变体（Alg.2）。
- **CSI 口径**：数据集=MNIST、CIFAR-10、CelebA、AFHQ（自然图像，无雷达和临近预报任务）；帧=不适用（单张图像的复原或生成，没有时间维）；分辨率=论文未写明复原实验的分辨率；代码中 MNIST/CIFAR-10 的 image_size=32（mnist_train.py、cifar10_train.py），CelebA 为 128（celebA_128.py）。生成实验是 128×128 CelebA/AFHQ（§5.2 p8，Fig.7 p9）；刻度=代码里图像归一化到 [-1,1]（Dataset_Aug1/Dataset: transforms.Lambda(lambda t: (t*2)-1)，L995/L1017）；阈值=不适用：没有 CSI，指标是 FID/SSIM/RMSE（Tab.1–6）；聚合=不适用（无 CSI）；出处=§4 p5（本节 FID 相对测试集计算；但 Tab.2 的正文 p6 注明修补任务的 FID 相对 held-out 验证集）；Tab.1–2 p6、Tab.3 p7、Tab.4 p8（重建列 SSIM/RMSE 数值和列名对不上，很可能是论文排版错误，勿引用）、Tab.5 p9、Tab.6 p15；代码 deblurring_diffusion_pytorch.py 的 p_losses（L963–975）、forward（L980）、sample（L394–454）

### Generative Modeling through the Semi-dual Formulation of Unbalanced Optimal Transport (UOTM)

- **ID**：arXiv 2305.14777　**Venue**：NeurIPS 2023
- **Venue 依据**：PDF p.1 页脚注记 "37th Conference on Neural Information Processing Systems (NeurIPS 2023)."；arXiv v3（6 Feb 2024，p.1 侧注）；代码 README 标题写 "(Neurips, 2023)"
- **代码**：有代码（已 git clone 并用 git ls-remote 确认，HEAD 3c8866f，2024-05-03）。train.py 含完整对抗训练循环：errD_real=phi_star2(-D_real)；errD_fake=phi_star1(D_fake - tau*／／x0_pred-noise／／²)；生成器 err = tau*cost - D_fake（线性，不套 phi）；R1（r1_gamma 默认 0.2）；tau 默认 0.001。另有 train_toy.py，utils.select_phi 提供 linear/kl=exp/chi/softplus 四种 Ψ*。没有 CSI 评估代码，只算 FID/IS。jaemoo-choi/Unbalanced-Optimal-Transport-Generative-Model 与此仓 HEAD 相同，为同仓重定向。README 写 CelebA-HQ FID 5.80，与 PDF Tab.3 的 6.36 不一致，以 PDF 为准。（https://github.com/Jae-Moo/UOTM）
- **阅读层级**：全文PDF　**核查结论**：corrected　**任务**：B
- **一句话**：把 UOT 半对偶形式（边缘用 KL 软约束，Ψ*(x)=e^x−1）做成 GAN 式训练：势函数 v_φ 当判别器，传输映射 T_θ(x,z) 当一步生成器。无条件图像生成结果为 CIFAR-10 FID 2.97、CelebA-HQ 6.36。论文明确只利用 UOT 的离群鲁棒性，不用质量增减（p.3）。对我方而言只是 UOT 相关工作的引用位，外加一个类比性的'KL 松弛会压低稀有模态'警示，不是能直接涨 CSI 的零件。
- **CSI 口径**：数据集=CIFAR-10（50k，32×32）；CelebA-HQ（原文称 120,000 张，256×256）；1D 高斯混合 toy（各 4000 样本）；离群实验为 CIFAR-10 + 500 张 MNIST（约 1%）。无任何雷达/降水数据；帧=不适用（无条件图像生成，源为 N(0,I) 噪声；Small 模型用 3×8×8 高斯双三次上采样作源；Tab.1 toy 源为双高斯混合）；分辨率=32×32 / 256×256；刻度=图像像素线性映射到 [-1,1]（2x−1，App.B.1 p.18）；阈值=无 CSI；指标为 FID、IS（5 万生成样本）、kNN-KL（k=2，App.B.2 p.18）；聚合=不适用：论文与代码 train.py 都不计算 CSI；出处=PDF Sec.5 p.6–9、App.B p.17–18、App.C p.19；代码 github.com/Jae-Moo/UOTM/train.py
